# ☁️ Fylo Data Storage Component – Frontend Mentor Challenge

### 📌 About the Project

This project consists of a **data storage usage component**, developed as part of a **Frontend Mentor** challenge.  
The goal was to recreate the provided design using only **HTML and CSS**, focusing on semantic structure, layout organization, and visual accuracy.
This project reinforces core front-end fundamentals without the use of JavaScript.

### 🛠️ Technologies Used

[![My Skills](https://skillicons.dev/icons?i=html,tailwind)](https://skillicons.dev)

### 🧠 Learnings

During the development of this project, it was possible to:

- Practice building UI components with semantic HTML.
- Improve layout and positioning skills using CSS.
- Work with visual hierarchy, colors, and typography.
- Strengthen attention to detail to closely match the challenge design.
